# PIF — Programação Imperativa e Funcional

Repositório destinado às atividades, exercícios e práticas desenvolvidas na disciplina de **Programação Imperativa e Funcional (PIF)** da **CESAR School**.

##  Organização

As atividades estão organizadas por listas e capítulos, com uma pasta específica para cada conjunto de exercícios.



###  Questões teóricas

As respostas das questões objetivas e abertas de cada lista ficam reunidas em um único arquivo:

```text
respostas.md
```

O arquivo utiliza **Markdown** para facilitar a leitura diretamente pelo GitHub.

###  Questões práticas

Cada exercício de programação possui seu próprio arquivo `.c`.

Exemplo:

```text
ex01.c
ex02.c
```

Os exercícios não são agrupados em um único arquivo, facilitando a organização, compilação e avaliação individual de cada questão.

##  Tecnologias e ferramentas

* **Linguagem:** C
* **Editor:** Visual Studio Code
* **Compilador:** GCC
* **Versionamento:** Git
* **Repositório:** GitHub



##  Objetivo

Este repositório tem como objetivo registrar minha evolução ao longo da disciplina, reunindo exercícios de programação, respostas teóricas e práticas desenvolvidas durante o semestre.

A proposta é utilizar cada lista como uma oportunidade de **praticar, testar, errar, depurar e compreender os conceitos de programação**.
